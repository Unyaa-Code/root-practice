# 方案元素练习器

一个轻量、开源的网页端输入方案元素（字根、两笔、音节等）练习工具，专为输入法方案学习者设计。  
由《呜喵码》作者 mono、铁圈、冬山秋木 借助 AI 技术共同开发。

## 功能特性

- **元素闪卡练习** — 导入元素文件后，逐条展示元素并输入编码，答对自动推进，答错抖动提示
- **多种循环模式** — 适配不同学习场景
  - **间隔重复** — 基于多级间隔循环算法，实现高效重复学习
  - **顺序确认** — 每个元素仅出现一次，全部通过后进入下一轮，适合完整遍历学习
- **首码模式** — 仅需输入编码首字母即可判定正确，适合快速浏览元素
- **元素高亮** — 通过正则表达式匹配特定元素并以自定义颜色高亮显示（支持浅色/深色双主题配色）
- **表头配置** — 在元素文件中以 `#变量名: 值` 格式定义练习模式、字体候补、高亮规则等，导入时自动生效
- **进度持久化** — 字库、练习进度、设置均通过 IndexedDB 本地保存，刷新页面不丢失
- **进度导入/导出** — 支持导出进度字符串或含表头+元素的完整配置文件，便于跨设备迁移与分享
- **夜间模式** — 一键切换深色主题，所有 UI 自适应
- **自定义字体** — 支持导入 ttf/woff/woff2 字体文件（最多 2 个），适配各类元素字体
- **字号与排版** — 元素字号、答案字号、输入框字号、提示字号、垂直间距均可自由调节，每项支持一键重置为默认值
- **元素数量自适应** — 可根据元素数量自动换行或缩小字号，适配长短不同的元素
- **完全本地化** — 所有数据仅在本地处理，不会向任何服务器发送数据；使用精准 key 清理策略，不影响其他 `file://` 应用的存储

## 使用方法

1. 打开 `index.html`（无需服务器，直接双击即可使用）
2. 点击「📁 选择元素文件」导入元素数据
3. 看到元素后，在输入框中键入对应编码
   - 输入正确：自动跳转到下一条
   - 输入错误：输入框抖动提示，该元素重新开始
4. 开启「首码模式」后，只需输入编码的第一个字母即可
5. 开启「顺序确认」后，按顺序逐一确认每个元素，完成一轮后可继续下一轮

## 元素文件格式

纯文本文件，可选表头参数

### 表头配置行（以 `#` 开头）

可在文件开头定义练习参数，导入时自动应用：

| 变量名 | 值格式 | 说明 |
|--------|--------|------|
| `顺序确认模式` | `true` / `false` | 是否开启顺序确认模式 |
| `字体候补` | CSS font-family 字符串 | 设置使用的字体 |
| `高亮规则` | `浅色=#rrggbb 深色=#rrggbb 正则=正则表达式` | 定义一条高亮规则 |

**表头规则：**
- 以 `#` 开头的行为配置行，其余为数据行
- 配置项顺序可任意排列，也可缺失任意项
- 颜色格式必须为 `#rrggbb`（6位十六进制），格式错误时会警告但自动使用随机颜色替代
- 多条 `#高亮规则` 按出现顺序排列，上方规则优先匹配
- 值可直接从设置面板复制使用

### 数据行

以 Tab 分隔的元素记录：

```
元素	编码	提示（可省略）
```

示例：

```
日	ri	晶
几	ji
人	r	队 今
```

- 第一列：元素（显示在练习区域）
- 第二列：编码（输入匹配的目标）
- 第三列：提示（可选，显示在元素下方）

### 完整示例：

```
#顺序确认模式: true
#字体候补: Unyaa-code-PUA, 'Noto Sans SC', sans-serif
#高亮规则: 浅色=#ff4444 深色=#cc3333 正则=日|月
#高亮规则: 浅色=#44aa44 深色=#338833 正则=人|大
日	ri	晶
几	ji
人	r	队 今
```

## 数据存储

所有数据均存储在浏览器本地，不会向任何服务器发送数据。
