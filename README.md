# 字根练习器

一个轻量、开源的网页端字根练习工具，专为形码输入法学习者设计。由《呜喵码》作者 mono、铁圈、冬山秋木 借助 AI 技术共同构建。

## 功能特性

- **字根闪卡练习** — 导入字根文件后，逐条展示字根并输入编码，答对自动推进，答错抖动提示
- **首码模式** — 仅需输入编码首字母即可判定正确，适合快速过字根
- **间隔重复** — 内置多级间隔算法，已掌握的字根自动后移
- **进度持久化** — 字库、练习进度、设置均通过 IndexedDB 本地保存，刷新不丢失
- **进度导入/导出** — 可将进度序列化为字符串，跨设备迁移
- **夜间模式** — 一键切换深色主题
- **自定义字体** — 支持导入 ttf/woff/woff2 字体文件（最多 2 个），适配各类字根字体
- **字号与排版** — 字根字号、答案字号、输入框字号、提示字号、垂直间距均可自由调节
- **字根数量自适应** — 可按字根数量自动换行或缩小字号，适配长短不同的字根

## 使用方法

1. 打开 `index.html`（无需服务器，直接双击即可使用）
2. 点击「📁 选择字根文件」导入字根数据
3. 看到字根后，在输入框中键入对应编码
   - 输入正确：自动跳到下一条
   - 输入错误：输入框抖动提示，该字根重新开始
4. 开启「首码模式」后只需输入编码第一个字母即可

## 字根文件格式

纯文本文件，每行一条，以 Tab 分隔：

```
字根	编码	提示（可省略）
```

示例：

```
日	ri	晶
几	ji	朵 风
人	r	队 今
```

- 第一列：字根（显示在练习区）
- 第二列：编码（输入匹配的目标）
- 第三列：提示（可选，显示在字根下方）

## 数据存储

所有数据均存储在浏览器本地：

- **字库与进度** → IndexedDB（`ZigenPracticeDB`）
- **设置** → localStorage
- **自定义字体** → IndexedDB（最多 2 个）

不会向任何服务器发送数据。
